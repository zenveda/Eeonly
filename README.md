# Eastern Europe Only

A single-page web app that greets developers with a random insult from an Eastern European engineer.

## Features

- 23 unique insults voiced by developers from Poland, Romania, Russia, Ukraine, Bulgaria, Czech Republic, Slovakia, and Hungary
- New random insult on every page load or refresh
- "Another One" button to cycle through insults without repeating

## Usage

Open `index.html` in any browser. No build step, no dependencies.
